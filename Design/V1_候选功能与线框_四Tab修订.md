## 1. 这次快速上线要做成什么样

**一句话定位：** 一款以猫狗为主、可以建立宠物档案、记录照片日记、管理喂养与健康、查看成长过程的轻量宠物生活 App。

**核心使用闭环：**

```text
第一次打开
   │
   ▼
添加宠物（猫 / 狗 + 名称 + 头像）
   │
   ▼
首页看到宠物和今天的待办
   │
   ├────► 添加日记 / 照片 ───► 时光中查看
   │
   ├────► 记录喂食 ─────────► 历史记录
   │
   ├────► 记录体重 ─────────► 简单趋势图
   │
   └────► 添加护理提醒 ─────► 到期提醒 / 确认完成
                 │
                 ▼
         随时编辑、导出重要内容
```

**上线原则**

- **以记录为主，不做复杂平台：** 不需要账号注册、宠物社区、服务器、在线交易或持续 GPS 追踪才能正常使用。
- **可离线使用：** 常规记录数据以本地为主。联网服务若选择进入 V1，也不得阻断本地使用。
- **初始支持多只宠物：** 可以切换管理不同宠物；「宠物小家」复杂分组单独选。
- **照片或 Q 版形象可以作为首页主视觉：** Q 版完整定制、丰富动画等仍属于高成本项，需要合理收敛。
- **固定四个主导航：** 首页 / 时光 / 宠物 / 我的，并提供独立「＋」快捷添加入口。
- **基本质量门槛（不单独选择）：** 编辑 / 删除确认、空状态、输入校验、深浅色模式、基础字体缩放、减少动态效果、权限说明和数据不丢失。

## 2. 主要功能：建议默认纳入 V1（可取消）

### A. 宠物与首页

- [x] **M01｜多宠物基础档案**：支持猫 / 狗；名称、照片、性别、品种、生日等基本资料；增删改查和宠物切换。

- [x] **M03｜基础静态 Q 版形象**：少量猫狗外形模板、常用毛色 / 花纹、基础胖瘦选择；不依赖 AI 生成；**不要求首版就覆盖所有品种和动作**。
- [x] **M04｜轻量首页**：当前宠物的形象、今日提示、最近记录和快捷添加；界面以宠物为中心。

### B. 日记与时光

- [x] **M05｜日记 + 照片**：写文字、选多张照片、关联宠物、选择发生日期；可编辑和删除。
- [x] **M06｜成长时间线**：按日期查看日记、照片、喂食、体重、护理等记录，支持切换宠物。
- [x] **M07｜基础照片墙**：集中查看已关联的照片，点击进入关联记录；不做 AI 自动整理。

### C. 喂养与健康

- [x] **M08｜喂食记录**：记录食物、数量、时间、宠物，查看最近历史。
- [x] **M09｜体重记录与简单曲线**：记录体重、日期，展示历史列表和折线趋势。
- [x] **M10｜疫苗 / 驱虫基础记录**：手动记录日期、项目、备注，允许关联下一次提醒。
- [x] **M11｜待办与本地提醒**：按宠物设置日常护理或重要日期提醒；区分待处理与已完成。

### D. 分享与资料安全

- [x] **M12｜基础分享卡片**：用照片或 Q 版形象生成一张简洁宠物名片 / 日记图片，通过系统分享；暂不做复杂模板编辑器。
- [x] **M13｜本地存储 + 基础资料导出**：重要记录落地保存；支持将选定记录导出为可读文件（如 CSV）并通过系统文件 / 分享菜单保存。

**默认推荐共 13 项。** 这是一组相对完整的上线闭环，不代表实现上述模块的所有已讨论高级能力。

**二级页定义：**

- **外观与显示**：跟随系统/浅色/深色；正确适配系统 Dynamic Type；减少动态效果跟随系统。不是自建与系统对抗的无障碍设置。
- **通知与提醒**：展示系统通知授权状态，提供疫苗/驱虫、日常护理提醒管理入口。待办与真实事件分离，通知关闭后计划仍保留。
- **本地数据管理**：本地宠物/记录/媒体的数量或空间概览、数据保存说明、M13 可读 CSV 导出、权限说明；演示数据不应硬编码。
- **隐私与权限**：照片、通知的授权状态；权限由 iOS 系统管理，必要时跳转系统设置。
- **使用帮助与反馈 / 关于应用**：基本操作、反馈渠道、版本、隐私政策等基础信息。

**条件展示，不属于默认 M01–M13：** 完整恢复备份 O16、iCloud O17、历史 CSV 导入 O18、完整语言切换 O20、Siri O22 等未选功能只能在确定加入 V1 后显示。无账户体系时不显示“登录、注销、同步账号”。

## 5. 给 UI 设计 Skill 的统一约束

**只以这一版最终选中的模块生成页面；不要把未选功能自动画进 V1。**

- **平台：** iOS，SwiftUI 风格，默认以 iPhone 竖屏为线框基准；选中 O19 才扩展 iPad 大屏线框。
- **整体气质：** 温暖、干净、低饱和、轻松、有亲近感；视觉重点是宠物本人，而非统计仪表盘。
- **主导航固定：** 首页 / 时光 / 宠物 / 我的，共四个主 Tab，独立的中间「＋」只负责快捷添加，不作为 Tab。
- **页面信息密度：** 小到中等，首页大面积留给宠物形象；宠物 Tab 只展示列表概要，点进二级才展示资料；时光顶部提供可组合筛选，筛选组件尽量收敛。
- **Q 版方向：** 统一毛绒公仔感，保留猫狗真实物种和毛色特征；无多余四肢 / 尾巴，静态方案优先。
- **视觉交付：** 先按本文线框做高保真 UI，再讨论颜色、组件、动画；不要依据线框自行发明大模块。
- **深浅色与动态效果：** 支持系统外观和减少动态效果；主要操作不用复杂手势才能触达。
- **内容真实性：** 演示数据可用占位，正式不自动编造健康、喂食、事件历史。
