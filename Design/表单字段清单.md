============================================

类型数据：真实账号登录后从官方服务器拉取（2026-10-27）。

一、新建提醒表单
--------------------------------------------
界面结构：顶部选类型，下方"其他设置"区逐项填写。

  1. 提醒类型 —— 点开选择（下表 25 种 + 自定义）
     未选时显示：请选择；选过显示类型名；可点"重新选择"换
  2. 选择宠物 —— 点开宠物列表选一只（家里只有一只时自动填好）
  3. 重复类型 —— 从不/每天/每月/每年/每周/自定义
     （选"自定义"进二级页：滚轮选每 N 小时提醒一次）
  4. 提醒铃声 —— 金铃/雪橇铃铛/卡通鼓拍/鼓钹/春天/弹簧/默认(系统)
     旁边有音量滑条；系统音量低时会提示"您当前的系统音量低"
  5. 开始日期 —— 点开日历选（提示：选择日期的时候，请注意大小月份哟~）
  6. 提醒时间 —— 点开滚轮选（小时 00-23，分钟每 5 分钟一档）
  7. 备注 —— 输入框，提示：Enter notes
  8. [删除] 按钮（编辑已有提醒时出现）
  9. [创建提醒] 按钮 —— 保存

校验逻辑（反编译 PlanEditActivity）：
  未选类型 → "请选择提醒类型"；未选日期 → "请选择开始日期"
  未选时间 → "请选择提醒时间"；修改 → "提醒设置更改"确认
  过期 → "闹钟已过期，X 后 闹钟将被启动"
  删日历权限 → "您需要日历权限来使用提醒功能哦~"
  删除 → "确认删除该提醒吗？"→"删除成功"

附：各表单的服务器保存接口
--------------------------------------------
  提醒 → alarm/savealarm         记事 → book/saveBook
  病历 → record/saveException    囤货 → alarm 相关
  记账 → book/saveBook(带类型)   宠物 → pet/addpet
  自定义类型 → alarm/petnotetypesadd

数据来源：
  表单字段 → 反编译布局 XML（activity_plan_edit / dialog_plan_edit /
    dialog_daily_record_list_edit / activity_medical_record_edit /
    activity_stock_edit / activity_account_create / activity_pet_edit /
    activity_abnormal_edit）
  内置类型 → alarm/alarmlist 服务器实拉（183 项，alarm-types.json）
