# 记录类型图标素材

使用内置 image_gen 工具逐张生成，风格参考为 `public/assets/sticker-icons.png`：深炭色手绘描边、淡黄 / 珊瑚粉 / 鼠尾草绿 / 浅蓝填色和轻微纸张质感。

五类模板共 183 个条目、125 个不同名称。同名条目共用图标；不同名称各有独立素材，保持原有模板名称、编号和顺序。涉及动物的图案统一使用猫咪；历史犬类名称使用通用物件图案。

- `原图/`：125 张透明 PNG 生成原图。
- `../../public/assets/type-icons/`：供 App 使用的 256 × 256 透明 WebP，原图保持不变。
- `manifest.json`：每个模板的素材映射、原图尺寸、SHA-256 和完整生成提示词。
- `index.html`：分类检索、48px 实际大小、浅色和深色底预览，以及每张图的下载入口。通过项目开发服务打开。
- `../../scripts/type-icon-specs.mjs`：统一风格要求和逐类型主题说明。

前端通过 `src/type-icons.json` 选择图标；自定义模板仍使用用户选定的图标。

补充原图后，可在安装了 sharp 的 Node 环境运行 `node scripts/build-type-icons.mjs`，重新导出 WebP 与映射。脚本检查类型覆盖和透明通道；它仅压缩导出素材，不修改原始插画。开发过程可用 `--partial` 暂时导出已完成部分，最终交付必须通过完整检查。
