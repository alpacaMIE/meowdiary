# 喵日记 · Meow Diary

根据 `Design/` 中的视觉稿与类型清单实现的移动端前端原型。React 19 + Vite 6，纯前端，无服务器、账号或云同步。

## 运行

```powershell
npm install
npm run dev
```

打开 http://127.0.0.1:5173 。桌面以居中的移动端界面展示，手机宽度下自动铺满。

```powershell
npm run build
npm run preview
npm test
npm run check:types
```

生产构建在 `dist/` 中，可部署至任意静态 HTTP 服务器。不要直接双击 `index.html`，它需要通过 HTTP 加载模块。

## 已实现

- 首页、时光、宠物、我的四个 Tab；中央「＋」为独立创建入口。
- 记事 85 项、提醒 25 项、记账 50 项、体征 20 项、囤货 3 项；均从原文自动提取，保留原顺序及重名项。每组支持搜索和自定义名称、图标。
- 日记、喂食、体重、护理及五组类型对应的新增、查看、编辑、删除流程；表单校验和未保存退出确认。
- 多宠物、类型、日期、排序与文本组合筛选；时间线和照片墙共享筛选。
- 宠物搜索、猫狗筛选、资料建档、照片上传、静态形象毛色与体型配置。
- 体重曲线、历史记录、护理记录、独立待办计划、周期提醒。
- 浅色 / 深色 / 跟随系统；响应系统减少动态效果设置。
- 按宠物、类别和日期导出 UTF-8 CSV；下载宠物 PNG 分享卡片。
- 本地存储概览、权限说明、帮助、空状态和存储失败反馈。

初始的团子、小米和历史内容为演示资料。用户数据通过浏览器 `localStorage` 保存，存储键为 `meow-diary-v1`。图片在浏览器中压缩后保存，存储失败不会清空表单。清除站点数据会删除本地资料；CSV 不包含照片原件，也不是可恢复备份。

通知是浏览器能力，仅在用户授权且页面打开时检查，不具备后台推送能力。未加入登录、云端同步、真实定位或天气服务。

## 设计与素材

原始设计保存在 `Design/`，未修改。前端实现与原稿中的 SwiftUI 技术建议分开，以用户要求的 Web 前端为准。中央「＋」按用户指定的完整类型清单扩展。

三张图片使用内置 imagegen 生成，保存在 `public/assets/`。素材提示词与来源见 `ASSETS.md`。图标使用 Lucide；图表为本地 SVG，无外部请求。

## 验证

`npm test` 覆盖多条件交集、空选集、排序、日期边界、照片范围、CSV 转义与公式注入防护，以及计划与实际记录分离。

`npm run check:types` 将生成的 `src/types.json` 与原始类型清单逐项比较。更新原始清单后，可运行 `node scripts/import-types.mjs` 重新生成。

浏览器验收页 `http://127.0.0.1:5173/qa/mobile.html` 同时展示 375px 与 320px 的窄屏布局。
